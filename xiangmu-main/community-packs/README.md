# community-packs · 社区规则包

规则包分享没有后端、没有账号系统——分享 = 交换 `.rulepack.json` 文件。

- 想把你的规则包分享给所有人：向本目录提交 PR，文件格式为 `aiobs.rulepack/1`
  （在应用内「标注规则 → 导出规则包」即可生成）。
- 收录标准（与内置目录同一校准纪律）：
  1. `validateRuleset` 通过；
  2. 在录制示例 trace 上命中率 >0 且 ≤30/100 token——命中为 0 说明规则失真，
     刷屏说明阈值过松，都退回校准。
- 阈值必须写明在哪份真实数据上校准过（trace 步数 + 命中率）。
