# AI Microscope · Design Language

> 定位：不是 AI 聊天，不是 AI 助手。这是一台**科学仪器**——帮助普通人真正观察 AI 的运行过程：Tokenizer、Embedding、Attention、Sampling、Reasoning、Token、Entropy、Probability、Agent。
>
> 本文档不是视觉规范的堆砌，而是回答一个问题：**一个世界级的「AI 显微镜」应该长成什么样、为什么。**
> 先立法，后动手。本文不含代码，不改任何页面。

---

## 0. 现状诊断（为什么需要重立 Design Language）

通读整个项目后的结论：产品的**数据诚实度已经是世界级的**（一切读数来自真实 trace、缺数据诚实缺席、失败如实入档），但**视觉语言还停留在「炫技的暗色仪表盘」阶段**，与「科学仪器」的定位存在系统性偏差：

| 症状 | 证据 | 违反的定位关键词 |
|---|---|---|
| 字号无系统 | 全站出现 15+ 种临时字号（9px–32px 逐 0.5px 微调），`text-[10.5px]` 用了 96 处 | Precision |
| 语义色失控 | indigo / amber / emerald / rose / sky / cyan 散落在 12+ 个组件里各自为政，仅 ObservePage 就 102 处 | Scientific, Calm |
| 「魔法感」残留 | 辉光呼吸（anomaly-glow）、粒子飘散、blur 弥散、渐变面积图、3D 概率海洋的氛围光 | 不要 Magic / Glowing |
| 暗色近黑机身 | `#0e0f12` 近黑底 + 霓虹 indigo 高亮，气质接近 crypto dashboard 而非实验室 | 不要 Cyberpunk / Dashboard |
| 卡片即容器 | 大量圆角卡片 + 阴影堆叠，信息靠「装进一张张卡」组织，而不是靠网格与对齐 | Laboratory, Professional |
| 动效偏叙事表演 | Birth Scene 凝聚/飘散、粒子成字等 600ms「场面」，是电影语言不是仪器语言 | Calm, Evidence |

一句话诊断：**数据层是科学家，皮肤是科幻片。** Design Language 的任务是让皮肤配得上数据。

---

## 1. 北极星：仪器，不是舞台

参照系不是 ChatGPT，也不是任何 AI 产品。参照系是：

- **示波器 / 光学显微镜**——读数永远清晰，仪器本身永远安静；
- **Chrome DevTools Performance 面板**——高密度真实数据 + 单色系底 + 极少但精准的语义色；
- **Linear / Raycast**——克制的层级、系统化的字阶、几乎不打扰的动效；
- **学术论文的图表**（Edward Tufte 传统）——最大化数据墨水比，去掉一切非数据像素。

由此得出唯一的设计判据，之后所有决策都用它裁决：

> **每一个像素要么承载证据，要么保持沉默。**
> （If a pixel doesn't carry evidence, it must stay quiet.）

「炫」不是问题，「炫得没有数据依据」才是问题。真实概率驱动的可视化可以保留，但表现形式必须从「表演」改为「测量」。

## 2. 设计原则（六条，按优先级）

### P1 · Evidence over Decoration（证据高于装饰）
任何视觉强调（颜色、动效、大小）必须由一个**可指认的真实字段**驱动，且用户能一步下钻看到该字段的原始读数。没有字段支撑的强调一律降为中性灰。装饰性渐变、氛围光、无数据含义的粒子：删除。

### P2 · Calm Instrument（仪器保持安静）
仪器不抢观察对象的戏。界面底色、边框、控件全部退到中性；唯一允许「动」的是**数据本身**。循环动画（呼吸、脉冲、辉光）只允许出现在「正在测量中」这一个语义上，且同屏最多一处。

### P3 · Measurement, not Storytelling（测量感优先于叙事感）
数字优先以「读数」形态出现：等宽数字、明确单位、固定小数位、可对齐的表格与坐标轴。人话解释（Story 层）保留，但它是读数的**注释**，排在读数之后，不替代读数。600ms 的「场面」改为 150ms 的「指针移动」。

### P4 · Density with Hierarchy(高密度 + 强层级）
科学工具不怕信息密，怕的是密而无序。用系统化字阶、8pt 网格、对齐线组织高密度信息；砍掉「一屏只留一句话」的空旷首屏倾向——观察者需要的是稳定的工作台，不是营销页。

### P5 · Honest Absence（诚实缺席）——继承现有宪法
无数据不渲染占位壳、不模拟、不脑补。这条项目已做到，Design Language 层面把它扩展到视觉：**加载态用真实进度，不用无限骨架屏；空态说明「缺什么字段、为什么缺」。**

### P6 · One Grammar, All Scales(同一语法贯穿所有尺度）
Token 级（一次采样）、运行级（一次生成）、任务级（一次 Agent 协作）用同一套视觉语法表达同类概念：概率永远是同一种条形、时间永远是同一种轴、不确定性永远是同一种表示。用户学一次，处处能读。

## 3. 基础语言（Foundations）

### 3.1 色彩：一个中性底 + 三个测量色

**底色系（唯一主角是纸，不是黑）**
- 主工作台改为**冷灰白实验室底**（纸感，接近论文/DevTools 浅色），暗色保留为可选的「暗室模式」（观察发光样本用），但暗室底从近黑 `#0e0f12` 提亮为深石墨，去掉蓝色偏移——黑底霓虹是 crypto，深灰纸是仪器。
- 层级靠**明度阶梯 + 1px 硬边框**建立，不靠阴影。阴影只保留给真正浮起的层（弹层/抽屉）一档。

**测量色（语义固定，全站唯一事实源）**
| 色 | 唯一语义 | 用途示例 |
|---|---|---|
| 测量蓝（一种，非霓虹 indigo） | 「当前被测对象 / 可交互」 | 选中 token、当前步、主按钮 |
| 警示琥珀（一种） | 「不确定性高 / 需要注意的测量值」 | 高熵、犹豫点、慢步 |
| 判定红（一种） | 「失败 / 越界」 | 检索失败、生成报错 |

- emerald / rose / sky / cyan / violet 全部收编：成功用「中性 + 对勾」表达，不需要绿色；多系列对比图表用**明度与线型区分**，不用彩虹。
- 连续量（概率、熵）用**单色梯度**（同一测量色的明度阶），永不用多色彩虹梯度。

### 3.2 字体：双字体制

- **界面与正文**：现有 Inter/系统栈保留。
- **一切读数（数字、单位、token 原文、ID）**：等宽字体 + `tabular-nums`，无一例外。读数与文字在视觉上必须一眼可分——这是仪器与网页的分水岭。

**字阶收敛为 6 档**（替换现有 15+ 种临时字号）：

| 档 | 用途 |
|---|---|
| Display | 页面唯一大标题（每屏最多 1 个） |
| Title | 区块标题 |
| Body | 正文、解释句 |
| Reading | 读数（等宽） |
| Label | 轴标签、字段名、小节 caption |
| Micro | 单位、脚注（最小档，禁止再往下发明 9px） |

任何 `text-[10.5px]` 式的临时值视为违规，必须归档到六档之一。

### 3.3 空间与形状

- **8pt 网格**：间距只允许 4/8/12/16/24/32/48。
- **圆角两档**：控件 6–8px、容器 10–12px；取消胶囊按钮泛滥（full 圆角只留给状态徽章）。
- **边框优先于阴影，对齐优先于卡片**：同类信息用表格/网格对齐，不再「一事一卡」。卡片降级为分组工具，不是默认容器。

### 3.4 动效：指针语法

只保留三种合法动效，全部服务「测量」心智：

1. **指针移动**（150ms，ease-out）：数值变化、选中切换、进度推进——像仪表指针，快而准。
2. **展开/收起**（250ms）：下钻证据、折叠推理——空间语义，不是表演。
3. **测量中**（唯一允许的循环动画）：一个安静的采样指示（细进度或单点闪烁），同屏一处。

明令废止：辉光、粒子飘散、blur 弥散入场、缩放弹跳、彩色脉冲。`prefers-reduced-motion` 下 1、2 直切、3 静态。
现有 Birth Scene 的**数据**（top-k 真实概率、尾部质量）保留，但表现形式重构为「测量视图」：候选概率条的实时重排 + 塌缩瞬间的读数变化，而非粒子烟花。

### 3.5 图表语法（数据墨水优先）

- 面积渐变填充 → **细线 + 数据点**；网格线降到刚好可读。
- 概率一律水平条形（同一组件复用），熵一律单色深浅，时间一律横轴向右。
- 每张图必须自带：轴/单位、来源标注（「本机 trace 实录 · Top-N 截断」这一现有优点保留并制度化）、以及一步下钻入口。
- 3D（概率海洋）定位为**选配的观察方式**之一，服从同一测量色系统，去掉氛围光与霓虹材质；默认入口是 2D 测量视图。

## 4. 部件语法（Component Grammar）

以「仪器部件」而非「网页组件」命名与设计，全站只允许这七类部件，任何新 UI 必须归入其一：

| 部件 | 职责 | 现有组件归位示例 |
|---|---|---|
| **Specimen（标本区）** | 被观察对象本身：生成的文本、token 流 | TokenText、正文 |
| **Gauge（读数表）** | 单个实时读数：熵、概率、耗时、tok/s | MomentCard 的读数行、控制台读数 |
| **Trace（记录轴）** | 沿时间/步序的连续记录 | SentenceRibbon、AgentTimeline、曲线 |
| **Inspector（检查器）** | 选中对象的全字段下钻 | SamplingInspector、BirthCard |
| **Log（实录日志）** | 按发生顺序的事件流 | ActivityLog、关键时刻 |
| **Bench（操作台）** | 用户输入与实验条件 | composer、参数区 |
| **Protocol（协作流程）** | 多 Worker 的分工与交接 | TeamFlow、TeamPanel |

部件通用硬规则：
- 每个部件左上角有**等宽小字标签**（部件名 + 数据来源），像仪器面板上的丝印；
- 每个部件有完整四态：有数据 / 测量中 / 无数据（诚实说明缺什么）/ 失败（红色 + 错误原文）；
- 部件之间靠网格对齐，不靠嵌套卡片。

## 5. 语言与文案（Voice）

- **测量式陈述，不拟人营销**：「第 68 步 top-2 差 0.4%」是读数；「它差一点写了 X」是注释——两者都保留，顺序永远是读数可及、注释随后（现有 P27 证据链方向正确，保留）。
- 永不使用：魔法、神奇、智能涌现、赋能；不给模型编造意图（「它想要…」→「该步概率分布显示…它写下了…」的现有口径保留）。
- 单位与精度制度化：概率 1 位小数百分比、耗时 ms/s 自动换档、熵保留 2 位 nats——全站统一，写进 token 表。
- 术语双层：界面默认人话（「把握度」），hover/下钻露出学名（entropy），学名永远等宽。

## 6. 反面清单（Anti-patterns，一票否决）

1. 无数据含义的发光、辉光、粒子、blur 氛围。
2. 彩虹语义色、渐变按钮、玻璃拟态。
3. 无限循环的骨架屏 / 假进度。
4. 「AI 正在思考…」类拟人加载文案（改为「正在采样 · 第 N 步」）。
5. 为了「高级感」加大留白牺牲数据密度。
6. 卡片套卡片套卡片。
7. 任何六档之外的字号、三色之外的语义色、三种之外的动效。

---

## 7. 迁移优先级（不动代码，仅列顺序）

1. **Token 层**：色彩收编（3 测量色）+ 字阶六档 + 等宽读数——一次性置换 CSS token，全站生效，性价比最高。
2. **图表层**：渐变面积图 → 细线；概率条/熵深浅统一组件。
3. **动效层**：废止辉光/粒子，Birth Scene 重构为测量视图。
4. **布局层**：卡片堆 → 网格对齐的仪器面板；部件丝印标签。
5. **暗室模式**：近黑+霓虹 → 深石墨+测量蓝，降为可选主题。

## 8. 治理

- 本文件是视觉与交互的**唯一事实源**；与 `docs/design-language/`（ACDL 认知层规范：五层认知链、诚实缺席、证据链顺序）互补——ACDL 管「说什么、凭什么说」，本文管「长什么样、怎么动」。两者冲突时，数据诚实原则（ACDL）优先。
- 任何新页面/组件评审只问四个问题：
  1. 这个像素承载什么证据？
  2. 用的是七类部件里的哪一类？
  3. 读数是等宽的吗？能下钻吗？
  4. 它在无数据/失败时长什么样？
