# ACDL 01 · Questions（问题驱动导航 · P31）

> Layer 0：先定义用户脑子里真正的问题，再谈页面。页面导航、侧栏、入口全部按问题组织，不按功能模块组织（用户在找答案，不是在浏览功能树）。

## 1. 页面 = 问题（Question Organization）

| 现在的模块名 | 以后的本屏问题（P28 唯一问题） |
|---|---|
| Observe / 实况 | **AI 为什么写这个？** |
| Replay / 概率地形 | **AI 什么时候开始犹豫？** |
| Sampling Inspector / 采样显微镜 | **为什么换温度会改变答案？** |
| RAG Panel / 检索舞台 | **AI 为什么引用这一段？** |
| Agent Timeline / 规划 | **AI 为什么决定这样做？** |
| Compare | **两次运行从哪里分岔？** |

模块名保留在专业层与代码；用户界面以问题为标题与入口。

## 2. 读者层问题（锚定正文，随阅读产生）

问题必须来自用户阅读正文时自然产生的疑问，不是 AI Debug 问题：

| 问题（界面原文） | 证据来源（真实字段） | 展开呈现（按五层链：Pattern→Story→Meaning） |
|---|---|---|
| 为什么它写「形成」？ | 该步 topk + gap | 两根近等高条摇摆 → 胜者落下（Collapse）→「因为两个候选只差 0.1%，抽签选中了它」 |
| 为什么它没写「我」？ | 选中 rank>1 + 温度/seed | rank1 长条 vs 被抽中的短条 →「温度让第二名被抽中了」 |
| 为什么它突然去搜索？ | RetrievalRecord + 时机 | 检索前后上下文对照 + 命中/弃用文档流入（Flow） |
| 为什么这里写得特别慢？ | dt > 3× 均值 | 节奏轨凸起 →「这一步花了平时 N 倍时间」 |
| 为什么它先写了一份计划？ | agent plan 子运行 | 计划逐字流出（Flow）+ 耗时 + 交棒 |

## 3. 专业层问题（下潜，不删）

它什么时候开始犹豫？哪一步熵最高？再跑一次会一样吗？——现有决策时刻/事件徽章/Debug 归入此层。

## 4. 诚实缺席问题（P9）

「它为什么会想到 X？」「它在注意哪些词？」「它理解了吗？」——不出现，或明确标注「暂无法回答（需 attention/hidden state 导出）」。

## 5. Question Engine（代码层）

`lib/question/`：输入 Story[]，输出 Question[]（{ text, momentRefs, anchor(正文step), layer: reader|pro }）。UI 只读 Question/Story，不碰 Trace。
