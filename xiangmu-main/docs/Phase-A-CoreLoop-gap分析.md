## P0-1 · 阶 4「复现」被说、没被看见

**问题**：产品在多处**声称**可复现（"预期可复现""复现需同一模型版本…"），但从没**演示**一次复现。
这正是 Evidence First 最该出手的地方——"复现"是本产品对"AI 是确定性系统"这一反直觉认知的**决定性证据**，却停在文字承诺层。
`AODL/01` 阶 4 的判据是"同 seed 重放，**逐 token 一致**"——现状不满足"看见"。

**最小改动方向（打磨，非新模块）**：在已有 trace 上加一个"再跑一次（同 seed）"动作，把两次 run 逐 token 并排，
一致处安静、出现差异（换硬件/后端）才高亮。复用现有"两次 run 对比"基建（`DualTraceChannel.tsx` 已能并排两条 run + 二维叠加图兜底），不新造框架。
> 判据：用户能亲眼看到"第二次和第一次一模一样"，而不是读到"预期一致"。

## P0-2 · 认知原则六「先猜后验」缺席

**问题**：演示停在犹豫点后**直接揭示**两个候选概率（`ObservePage.tsx:928`），跳过了"让用户先猜"这一步。
`AODL/01` 原则六：每次揭示前，先请用户预测，再验证——这是学习科学里的预测误差，是"震撼"的放大器。
现在用户是**被告知**"它差点选另一个词"，而不是**自己猜错后被击中**。

**最小改动方向**：在犹豫点暂停帧，揭示前加一句轻量、可跳过的邀请（"你觉得它更可能说 A 还是 B？"），
点选后再翻牌真实概率。**必须可跳过**（P4 不设障碍/不打断主流），只做一次（首个犹豫点），不做成问答游戏。
> 判据：新用户在首个犹豫点先形成一个预期，再被真实数据确认或推翻。
