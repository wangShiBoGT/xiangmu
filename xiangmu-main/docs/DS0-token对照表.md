# DS0 · Design Token 对照表（校准记录）

> 目的：把宪法 §3 的 Design Token 固化为**唯一事实源**，并如实记录「宪法理想值 ↔ 项目现存主流值」的差异。
> 原则：token 固化 ≠ 大改视觉。凡会改变现有观感、且触及全站数百处类名的收敛（尤其字号），
> 均登记为「待确认债务」，需人类拍板后单独批次执行——不在本批次盲改（八荣八耻：以盲目修改为耻，以谨慎重构为荣）。

事实源位置：`src/index.css` 顶部 `:root` 的 `--motion-*` / `--radius-*` 变量块。

---

## 1. 动效 Motion

宪法三档：`150ms`（hover/按钮/toast）· `300ms`（展开/收起/抽屉/布局推移）· `600ms`（一次性叙事入场，每屏≤1）。

| Token | 值 | 用途 |
|---|---|---|
| `--motion-fast` | 150ms | hover、按钮反馈、caret 翻转、代码复制底色 |
| `--motion-base` | 300ms | 摘要浮出、展开/收起过渡 |
| `--motion-slow` | 600ms | 犹豫切片入场、完成摘要一次性叙事 |

Tailwind 工具类现状：全站仅用 `duration-150 / duration-300 / duration-600`（已合规，前批次收敛完成）。

**已登记豁免（不受 150/300/600 约束）——连续/环境动画，非离散 UI 过渡：**

| 动画 | 时长 | 性质 |
|---|---|---|
| `token-in` | 90ms | token 落位微反馈（比 fast 更短，刻意「瞬时」） |
| `.token-unit` transition | 120ms | 载玻片 hover/描边微反馈 |
| `.token-unit:active` | 40ms | 按压瞬时加深 |
| `pop-in` / `mask-in` | 180ms | 浮层生长（cubic-bezier 定制手感） |
| `drawer-in` / `focus-lens-in` | 240ms | 抽屉/检查器滑入 |
| `chamber-cand-in` | 180ms | 采样舱候选显影 |
| `chamber-drop` / `chamber-bar-pulse` | 450ms | 采样穿越阈面（概率驱动） |
| `breathe` 2.4s · `spin` 0.8s · `breath` 1.2s · `blink` 1s · `anomaly-glow` 3.2s · `demo-resume-pulse` 1.6s | 循环 | 呼吸点/spinner/光标/异常辉光——`infinite` 环境动画 |

> 说明：宪法 150/300/600 治理的是**离散 UI 过渡**；上述为连续环境动画或概率驱动的解释性动画，
> 有各自的手感曲线，强行套三档会破坏既有体验。均已在 `@media (prefers-reduced-motion: reduce)` 下降级。

**待确认债务（可选收敛）：** `pop-in`/`mask-in`(180) 与 `drawer-in`(240) 若要严格向 150/300 靠拢，属手感调整，需确认后再动。

## 2. 圆角 Radius

宪法三档：`8` / `16` / `full`。

| Token | 值 | 对应 Tailwind |
|---|---|---|
| `--radius-sm` | 8px | `rounded-lg` |
| `--radius-md` | 16px | `rounded-2xl` |
| `--radius-full` | 9999px | `rounded-full` |

项目现存主流值（`.tsx` 统计）：`rounded-full`×90 · `rounded-2xl`(16)×51 · `rounded-xl`(12)×32 · `rounded-lg`(8)×32 · `rounded`(4)×11。

**已登记校准值：** `rounded-xl = 12px` 与 `rounded`/`token-unit`=4px 为项目既有第 4/5 档。
- 12px：卡片/代码块/输入框大量使用，是宪法 8↔16 之间的既成中间档。视觉收敛（12→8 或 12→16）会改变全站观感，**登记为待确认债务**，本批次保留。
- 4px：token 单元/短标签的最小圆角，属功能性微圆角，保留。

## 3. 字号 Typography

宪法 7 级：`11 / 12 / 12.5 / 13.5 / 15 / 18 / 26`。

项目现存实际（`text-[Npx]` 统计，共 14 档）：
`11`×82 · `12`×77 · `13`×61 · `10.5`×51 · `12.5`×36 · `10`×36 · `11.5`×31 · `13.5`×14 · `15`×12 · `14`×12 · `24`×6 · `32`×2 · `18`×1 · `44`×1。

命中宪法档：`11 / 12 / 12.5 / 13.5 / 15 / 18`（缺 `26`，多出 `10 / 10.5 / 11.5 / 13 / 14 / 24 / 32 / 44`）。

**结论：字号收敛（14 档 → 7 档）触及全站数百处类名、会明显改变排版观感，且会推翻所有 DS5 快照。**
这属于「重设计」而非「token 固化」，**登记为待确认债务，需人类确认后单独批次执行**，本批次不动。
建议收敛映射（供确认时参考）：`10/10.5 → 11`、`11.5 → 12`、`13 → 12.5 或 13.5`、`14 → 13.5 或 15`、`24 → 26`、`32/44 → 26`（或新增展示级 token）。

## 4. 间距 Spacing

宪法：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`（8px 系）。项目 Markdown 节奏（`md-answer`）即以 4/8/12/16/24 为步进，已符合。Tailwind 间距工具类默认即 4px 系，合规。

## 5. 语义色 Semantic Colors（≤5）

| 语义 | 色 | 用途 |
|---|---|---|
| Accent | `--color-accent`（亮=近黑石墨 / 暗=`#6366f1`） | 可点击/主动作/focus |
| Amber | `amber-*` | 官方引用层（引用，非本机实测） |
| Green | `emerald-*` | 本机实测（延迟/吞吐/能力命中） |
| Red | `red-*` | 异常/失败 |
| Gold | `#f5b04c`（token-anomaly / rule-warn） | 极值/异常高亮 |

灰阶（ink / ink-2 / ink-3 / line）为中性层级，不计入语义色。合规（=5）。
