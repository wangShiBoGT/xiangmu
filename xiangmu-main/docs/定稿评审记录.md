# 三视角严格评审记录（评审 → 修订对照）

> 评审对象：`产品原则.md`、`总体规划-锚点.md`、`首屏文案稿.md` 初稿。
> 每条意见标注：视角 / 严重度 / 处理结果。已全部落实到修订版。

---

## 视角一 · AI 产品负责人

**R1（高）首屏切片自己违反 Evidence First。**
初稿切片只放两行「本身 20.08% / 这个词 20.08%」。但这两行只占概率质量的 40%，
其余候选合计 59.84%。只展示两行会诱导用户以为这是一枚二选一的硬币——这是用省略制造的误导，
恰好违反我们自己的 P1。
→ **已修订**：切片加第三行「其余 36 个候选合计 59.84%」，并在 P1 检验规则中新增一条：
「切片不得省略会改变结论的上下文」。

**R2（高）谜题句的证明闭环有缺口。**
谜题是「每次回答都不一样」，但演示只放一条 run，用户全程没看到「两次不同的回答」。
承诺与兑现之间隔了一层推理。
→ **已修订**：暂停帧解释层补一句 seed 伏笔（「同一个 seed，这枚硬币每次掷出同一面；换一个，就可能是另一个答案」）；
收束语第二按钮直接通向「换个 seed 再跑一次」的对比出口（复用已有 CompareView 能力，锚点 A6 验收补充）。

**R3（中）「回看这 15 个瞬间」按钮承诺了一个不存在的功能。**
按差距排序逐个跳转目前没有实现，按 P4 这个按钮不许上线。
→ **已修订**：A6 验收标准明确列出该跳转功能为批次 1 交付物；文案稿标注实现要求。

**R4（中）P0-3 KPI 不可直接测量。**
「用户产生『我没想到』瞬间」无法测。
→ **已修订**：P0-3 改为可测代理指标：看到犹豫点暂停帧的首访用户中，点击候选或「继续」的比例（由 A8 行为 trace 计算），并注明这是代理而非本体。

## 视角二 · 老板（资源与执行）

**B1（高）计划没有工作量与顺序依据，无法排产。**
→ **已修订**：每个批次标注粗粒度工作量（S/M/L）与依赖。

**B2（高）A9 用户测试的位置和失败预案缺失。**
测试放在批次 1 之后，但如果 7/10 不达标怎么办没有写。
→ **已修订**：明确 A9 在批次 1 上线后一周内执行；不达标则只迭代 A1–A4 文案层（不推翻结构），迭代同样走锚点变更规约。

**B3（中）单一 demo trace 是单点依赖。**
首屏切片、收束语全部押在一条 229 步的 trace 上；若换 demo trace，文案数字全变。
→ **已修订**：规划新增锚点 A10——切片与统计数字必须运行时从 trace 计算（初稿已有此意，升级为独立验收锚点），换 trace 零成本。

**B4（中）度量没有闭环。**
A8 收集了行为数据，但没人看。
→ **已修订**：A8 验收补充「设备页展示本机首访漏斗」，数据自己看得见才算闭环。

## 视角三 · 投资人（叙事与壁垒）

**V1（高）没有一句话定位声明与差异化陈述。**
规划罗列功能，但没有回答「你和其他 AI 可视化/logprobs 工具有什么不同」。
→ **已修订**：规划开头新增定位声明：别人做 AI Story（拟人化讲故事），我们做 AI Evidence（可核验证据）；
壁垒 = Evidence First 方法论 × 全本地零成本推理 × `.aitrace` 可复现格式。

**V2（中）KPI 只有好奇心指标，没有激活指标。**
好奇心证明入口，激活证明产品有腿。
→ **已修订**：P0-3 增加第二指标：首访用户中最终「跑了自己的 prompt」的比例。

**V3（低）商业化路径完全空白。**
现阶段不需要收入，但需要展示想过。
→ **已修订**：新增远期锚点 F1（企业规则包 / 团队实验档案为潜在货币化方向，明确标注 🔭 不承诺）。

**V4（低）「亲眼看这一刻」若加载超 10 秒即违反 P4。**
→ **已修订**：A4 验收补充：演示资源预加载或首帧兜底，超时给出真实等待说明（复用 BreathingWait 模式）。
