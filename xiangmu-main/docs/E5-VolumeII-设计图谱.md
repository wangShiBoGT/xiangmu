# AI Observatory E5 · Volume II · Design Atlas（设计图谱）

> 本卷拆解世界级产品的设计哲学。每个案例只回答四问：
> ① 为什么第一眼舒服 ② 为什么愿意继续探索 ③ 什么原则可迁移 ④ 什么不能学。
> 拆解的是原则，不是像素；本卷不含任何截图与实现方案。

---

## 第一章 · 拆解方法

一个界面「舒服」从来不是审美玄学，可以分解为四个可分析变量：

1. **密度节奏**：信息密集区与留白区如何交替——好的界面像乐句，有重音有休止。
2. **层级深度**：一眼能分出几层重要性——超过三层视觉层级，认知就开始排队。
3. **语言一致性**：同一语义是否永远同一表达——不一致强迫用户重新学习。
4. **承诺兑现率**：每个可点元素引发的预期，下一屏兑现了多少。

以下所有案例都用这四个变量拆。

## 第二章 · 案例拆解

### 2.1 Lovart（用户指定研究对象）

**为什么第一眼舒服**
主画布几乎全空，全部视觉重量压在两处：底部一条工具栏、右侧一栏对话。
它敢让 80% 的屏幕什么都没有——因为它知道用户的第一动作只有一个（输入想法），
其余一切都是「等被需要时才显形」。留白不是没设计，是替用户挡住了未来才需要的东西。

**为什么愿意继续探索**
Skills 以 pill chip 陈列：图标+四五个字的短语，一行扫过去像菜单而不像功能列表。
每个 chip 是一个具体的承诺（「Logo 设计」「一键跨平台适配」），点击的预期成本极低。
输入框里印着快捷键提示（按 C 开始对话）——教学藏在使用现场，没有新手引导浮层。

**可迁移原则**
- 首屏只服务第一动作，其余能力等被需要时显形（→ 我们首屏只有谜题+切片+一个 CTA，已一致；观察台需要再收敛）。
- 功能入口 = 图标 + 短承诺的 chip，可扫读（→ 规则包、示例 prompt、benchmark 过滤器）。
- 教学寄生在控件上（键盘提示、placeholder），不开独立教学层。
- 角标（余额⚡70）有固定的家：右上角、小、克制（→ 我们的来源角标挂载规则）。

**不能学**
- Lovart 是创作工具，它的「空」等待用户填充；我们是观察仪器，
  屏幕的主角是**数据**而不是用户的创作物——我们的「空」必须比它少，证据必须在场。
- 它的增长组件（升级会员横幅）随时插入工作区；我们的观察室里不允许任何推销物。

### 2.2 Linear

**为什么第一眼舒服**
全站只有一种节奏：行高一致的列表 + 键盘可达的一切。它把「软件」做成了「工具」——
没有一个界面元素在表达情绪，全部在表达状态。暗色不是风格，是长时间注视不疲劳的工程决策。

**为什么愿意继续探索**
速度本身是探索的邀请：每次点击 <100ms 响应，用户敢乱点，因为乱点没有代价。
Cmd+K 让「我想做 X」不需要知道 X 藏在哪。

**可迁移原则**
- 响应速度是信任的一部分：仪器的读数不能迟疑（→ 我们所有本地统计必须即时，长计算给真实进度）。
- 状态图标系统：一组小图标承载全部工作流状态，语义唯一（→ 我们的规则命中/结局分类图标）。
- 键盘语法全局一致（→ 未来 Cmd+K 式的「跳到第 N 步 / 搜索 token」值得纳入交互圣经）。

**不能学**
- Linear 的用户每天来 8 小时，学习成本可以摊销；我们的首访用户只给 8 秒，
  不能要求任何前置学习。快捷键是给回访者的糖，不是给首访者的门。

### 2.3 Apple（HIG 与产品页双面）

**为什么第一眼舒服**
产品页：一屏一句话一个主角，滚动即叙事——信息以「章节」而非「区块」组织。
HIG：控件的一切状态（默认/悬停/按下/禁用/聚焦）都被定义，没有「设计师没想到的状态」。

**可迁移原则**
- 滚动叙事：一屏一个论点，论点之间有呼吸（→ 我们首屏到收束卡的旅程已按此设计，D6 成绩单页应同构）。
- 完整状态定义：每个组件规格必须写满所有状态，尤其空态与失败态（→ Volume III 组件规格模板）。
- 「删到不能再删」：Rams 的 Weniger, aber besser——每加一个元素先问删掉行不行。

**不能学**
- Apple 的省略靠海量用户研究兜底，它可以隐藏复杂性因为它决定了平台惯例；
  我们是科学仪器，**该复杂的地方必须复杂**（P12：仪器不谎报自身），
  把口径说明省略掉的「简洁」在我们这里是违宪。

### 2.4 NASA Mission Control / Bloomberg Terminal（高密度仪表的两极）

**为什么值得研究**
这两者是「每个像素都因为有人要读它而存在」的极端：零装饰、高密度、
状态色语义恒定（红=异常，永远=异常）。它们证明高密度不等于混乱——
只要网格严格、语义色恒定、字体等宽对齐，人可以长期读高密度屏幕。

**可迁移原则**
- 数字必须等宽字体、右对齐、单位常驻（→ 我们 tabular-nums 已用，升格为规范）。
- 语义色恒定且稀少：一个颜色一个含义，全站不复用（→ 琥珀=引用、翠绿=实测、红=异常/退化，写死）。
- 「面板即口径」：Bloomberg 每个面板自带数据源标注（→ P14 来源分离的前辈）。

**不能学**
- 它们的用户是被雇佣来看屏幕的，可以承受陡峭学习曲线；我们的用户随时可以关掉标签页。
  高密度只允许出现在用户主动下潜后的深层（P10 分层披露），首层永远是低密度叙事。

### 2.5 Stripe（文档与仪表台）

**为什么舒服**
把「开发者产品」做出了纸质印刷品的秩序感：正文/代码/图表三种内容三种版式，
永不混排；图表克制到几乎朴素，但每根线都有图例、每个数都有单位。

**可迁移原则**
- 三种内容三种版式的严格分离（→ 我们的叙事文本/数据表/原始 JSON 三层版式分离）。
- 「文档级」可信感来自排版纪律而非视觉修辞（→ 报告纸体系的对标物）。

**不能学**
- Stripe 面向的读者带着明确任务（接入支付）而来；我们要先制造任务（好奇），
  它的开门见山不适合我们的首层。

### 2.6 Raycast / Arc（新一代工具的克制美学）

**可迁移原则**
- Raycast：一个输入框统治一切——复杂能力藏在统一入口之后，入口本身极简。
- Arc：敢于重新发明惯例，但每次发明都配一次现场教学（第一次用到时才教）。
- 二者共同点：动效只用于表达空间关系（哪里来、到哪去），时长极短（150–250ms）。

**不能学**
- 二者都是「使用频率极高的个人工具」，可以培养肌肉记忆；
  我们的产品语法（Question→Evidence→…）才是用户要学的唯一东西，交互惯例必须全部用现成的。

### 2.7 Anthropic / OpenAI / DeepMind（研究机构的传播设计）

**为什么值得研究**
它们的研究博客是「Evidence First 的传播形态」样本：交互图表让读者亲手改参数看结果
（DeepMind 的 distill 系传统），结论旁边挂着论文与数据。

**可迁移原则**
- 「可玩的图表」是最高级的证据形式：读者动手改一次，胜过读十句解释
  （→ E5a 温度反事实滑块正是此类，它是我们最像 distill 的功能）。
- 局限性声明与结果同版面（它们的 Limitations 章节，→ P12）。

**不能学**
- 它们的读者自带学术耐心；我们必须把同样的诚实包在好奇心叙事里（P3）。

### 2.8 CERN 科学可视化 / 示波器工业设计（仪器的本体）

**可迁移原则**
- 真实仪器的每个旋钮都有物理反馈与刻度；数字仪器的等价物是：
  每个可调参数改变时，读数的变化**即时且可见**（→ 温度滑块联动分布重算）。
- 示波器的「探头接哪，屏幕显示哪」——测量对象与显示的对应关系永远明确
  （→ 我们每张图表的「数据从哪条 trace 来」标注）。
- 仪器外观的克制：机身（chrome）永远比读数（data）暗一档
  （→ 我们的界面 chrome 用低对比，数据用高对比，对比度预算向数据倾斜）。

## 第三章 · 图标哲学（Icon Philosophy）

> 研究的不是图标本身，而是图标出现的场景纪律。

### 3.1 各家拆解结论

- **Apple**：图标出现频率极低，出现即承载导航或状态；文字能说清的地方不用图标。
- **Linear**：图标 = 状态机的可视化，一组 ~10 个状态图标承担全产品语义，重复使用形成语言。
- **Lovart**：工具栏图标单色细描边同网格；功能 chip 里图标只起「扫读锚点」作用，语义靠文字。
- **Raycast**：列表左侧图标是「身份」（哪个插件），不是「装饰」。
- **Perplexity**：来源角标（favicon 缩略）本身是证据的一部分——图标承载 provenance。

### 3.2 沉淀为我们的图标宪章

1. **图标是字体，不是插画**：单色、1.5px 描边、统一网格，permanently。
2. **语义唯一**：一个动作全站一个图标；一个图标全站一个含义。
3. **文字优先**：文字说得清的地方不放图标；图标必须配可见文字或 aria 标签。
4. **图标不下结论**：不用 emoji/表情性图标表达「好坏」，好坏由数据呈现
   （✓/✗ 只用于规则命中这类布尔事实，不用于价值判断）。
5. **来源角标是图标系统的一等公民**：琥珀引用标 / 翠绿实测标与导航图标同等级设计。
6. **单一来源**：图标只允许来自一个库（结合 Volume III 的判据确定 Hugeicons 或自绘系统），
   混库即违宪（P18）。库的选定标准：线条统一、覆盖科学/数据语义、许可证干净、五年检验（P24）。

### 3.3 填充与描边的唯一规则

Outline = 可用/未选中；Filled = 当前/选中。除此之外不存在第三种理由使用 Filled。

## 第四章 · 视觉语言基准（Visual Language）

> 数值规格属于 Volume III；本章只立哲学层的决定。

1. **网格**：12 列栅格；内容主栏恒定（阅读态 680–760px），全宽只留给数据可视化。
2. **间距**：8pt 体系（4 允许作紧凑半步）；任何间距必须是体系内的值。
3. **圆角**：三级制（小控件/卡片/胶囊），禁止体系外圆角值——圆角是层级信号不是装饰。
4. **字体**：叙事用无衬线；一切数字用等宽 + tabular-nums；token 原文用等宽并带可见边界。
   数字与文字永不混用同一字体族——读数感来自这一分离。
5. **色彩预算**：中性色不限；语义色全站 ≤5 个且含义恒定（accent、琥珀=引用、
   翠绿=实测、红=异常、金=最值高亮）；渐变禁止用于信息表达。
6. **阴影**：仅表达「浮起层级」（弹层/抽屉），平面内容零阴影——观察室里没有舞台灯。
7. **对比度预算**：chrome 低对比、数据高对比；一屏内最高对比度永远给当前证据。

## 第五章 · 反面清单（我们永远不学的东西）

- 营销页的「社会证明」修辞（logo 墙、用户数字大字报）——我们的证明是仪器本身。
- 赛博朋克/终端绿的「黑客美学」——那是表演科学，不是科学。
- 骨架屏伪装的加载速度——P16，等待即教学，不伪装。
- 无限滚动信息流——观察是有起点有终点的实验，不是刷不完的 feed。
- 弹窗式 NPS/评分乞讨——仪器不打断观察。
- 「AI 生成的插画风」装饰图——No Decoration（P6）+ No Fake Intelligence（P7）双重违宪。
