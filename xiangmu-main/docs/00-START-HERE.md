# AI Observatory · 文档入口

> 本页只解决一件事：**我现在该读什么，而不是该把所有东西读一遍。**

## 开工路线

1. 读仓库根 `AGENTS.md`。
2. 读 Kernel：`合规速查表.md`、`AODL/01-Cognitive-DNA.md`、`AODL/02-Visual-DNA.md`。
3. 接续、排期或问状态时读 `任务看板.md`。
4. 在 `AOKS/CONTEXT-ROUTER.md` 找任务行，只读那条链。
