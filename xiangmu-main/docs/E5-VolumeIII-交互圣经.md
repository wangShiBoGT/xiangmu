# AI Observatory E5 · Volume III · Interaction Bible（交互圣经）

> 本卷规定产品的交互语法、组件哲学、动效律法与视觉规格数值。
> 一切未来功能（Experiment / Benchmark / Agent / 社区）的交互从本卷派生，
> 不允许每个功能发明自己的交互方言。

---

## 第一章 · 交互语法（Interaction Grammar）

### 1.1 页面语法（继承宪法第五章）

```text
Question → Evidence → Interaction → Conclusion(用户产生) → Replay / Next Question
```

页面按此五段组织，段与段之间用留白分隔而非分割线——节奏靠呼吸，不靠栅栏。

### 1.2 下潜语法（Progressive Disclosure 的唯一实现）

全站只有一种「看得更深」的语言，三级恒定：

```text
第一级  陈述句（虚线下划线 + ⌄）      → 点击原位展开
第二级  证据卡（数据 + 来源路径行）    → 点击来源进入
第三级  原始层（trace 原文 / 原始 JSON）
```

- 下潜永远原位展开或右侧抽屉，**不跳页**——观察不允许丢失现场。
- 每级都有显式「收起」，且展开状态不改变周围内容的位置（预留高度或推挤动画 ≤300ms）。
- 任何新功能想让用户「点开看详情」，必须用这套三级语言，禁止新造弹窗/新页面模式。

### 1.3 时间语法（一切与生成过程相关的交互）

生成过程是产品的核心对象，其交互动词全站唯一：

| 动词 | 含义 | 惯例 |
|---|---|---|
| 播放/暂停 | 沿 trace 时间轴前进/停住 | 空格键；暂停态必有显式继续入口 |
| 步进 | 逐 token 前后移动 | ←/→；当前步永远高亮且居中 |
| 跳转 | 直达某个索引点（犹豫点/规则命中） | 点击列表行；到达后短暂脉冲标记现场 |
| 分岔 | 从某步换一个候选重跑 | 危险感为零的设计——分岔不破坏原 trace（P8） |
| 对比 | 两条 trace 并排 | 同源对齐（同模型 token 级 / 跨模型统计级，E3 口径） |
| 重放 | 同 seed 完整复现 | 结果逐 token 一致是产品的当众承诺 |

Agent 时间线（E4）到来时不新造动词：工具调用是时间轴上的一种「步」，
播放/步进/跳转对它同样成立。

### 1.4 悬停语法

- 悬停 = 预告，点击 = 承诺。悬停只显示轻量提示（数值、名称），绝不弹出重内容。
- 悬停出现的信息必须点击后仍可获得（触屏没有悬停，P19）。
- 悬停延迟 150ms 出现、离开即销毁；悬停内容自身不可再交互（可交互内容走下潜语法）。

### 1.5 键盘语法（给回访者的糖，不是给首访者的门）

- 空格=播放/暂停，←/→=步进,？=快捷键表。全部快捷键在对应控件上以 kbd 小方块常驻提示（Lovart 式现场教学）。
- 任何功能不允许「只有快捷键才能到达」。

### 1.6 状态语法（组件的五态齐全，Apple HIG 纪律）

每个交互组件规格必须定义：默认 / 悬停 / 按下 / 聚焦（键盘可见焦点环）/ 禁用。
外加两个产品特有状态：**空态**（诚实缺席文案 + 唯一下一步）与
**失败态**（如实报错 + 可重试）。七态缺一即规格不完整。

## 第二章 · 组件哲学（Component Philosophy）

> 对齐 component.gallery 的通用命名。每个组件回答：为什么存在 / 何时用 / 何时禁用。

**Timeline（时间轴）**
为什么：生成是时间过程，时间轴是它唯一诚实的形状。
何时用：一切「按步发生」的数据（token 流、Agent 事件、benchmark 进程）。
何时禁：无先后关系的数据强行摆成时间轴（伪叙事）。

**Tree（树）**
为什么：分岔实验天然是树。
何时用：Branch 结构、多层分岔导航。
何时禁：深度 >3 的树直接展示（应转为面包屑 + 当前路径视图，树是数据结构不是好界面）。

**Diff / Compare（对比）**
为什么：科学结论出自对照组。
何时用：同源可比数据（同模型双 seed、双结局、参数对照）。
何时禁：不可比数据的并排（跨模型 token 对齐，E3 红线）；无基线的单列数据伪装成对比。

**Inspector（检查器）**
为什么：仪器需要一个「探针读数窗」——选中什么，显示什么的全部。
何时用：当前 step / 当前候选 / 当前规则命中的详情，右侧固定区域。
何时禁：Inspector 里再嵌 Inspector（下潜请走三级语法）。

**Drawer（抽屉）**
为什么：临时借用空间且不丢失现场。
何时用：二级证据、设置、历史列表。
何时禁：核心观察内容放抽屉（主角不进侧台）；抽屉叠抽屉。

**Command（命令面板）**
为什么：回访者的直达通道（Linear 遗产）。
何时用：跳步、搜 token、切视图——远期统一入口。
何时禁：作为功能的唯一入口（1.5 键盘语法）。

**Split View（分屏）**
为什么：对照是分屏唯一正当性来源。
何时用：Compare、双结局。
何时禁：两个不相关任务硬凑分屏。

**Heatmap（热图）**
为什么：密度分布一眼可读。
何时用：有真实逐项数值的分布（熵沿序列的分布、规则命中密度）。
何时禁：**没有真实数据的示意热图（E5 红线：attention 无真数据就无热图）**；
颜色梯度必须配数值图例，否则是装饰（P6）。

**Panel / Card（面板）**
为什么：一个面板=一个口径（Bloomberg 纪律）。
何时用：每个独立测量/来源一张卡，卡角挂来源 Badge。
何时禁：一卡混两个来源（P14）；卡内再分不同来源的小节。

**EmptyState（空态）**
为什么：诚实缺席是合法终态（P9）。
规格：一句「为什么没有」+ 唯一下一步动作；禁止用插画填充尴尬。

**Toast（回执）**
为什么：操作需要确认但不值得打断。
规格：单条、3 秒、可含一个动作；禁止堆叠、禁止承载错误详情（错误走失败态）。

## 第三章 · Motion Bible（动效律法）

### 3.1 第一定律：动效必须解释

每个动效属于且仅属于以下四类之一，否则删除（P6）：

1. **空间解释**：东西从哪来到哪去（抽屉滑入、展开推挤）。
2. **时间解释**：过程正在发生（token 逐个出现——这是数据本身，不是动效装饰）。
3. **因果解释**：你的操作导致了这个变化（滑温度→分布条即时变形）。
4. **注意引导**：一次性把目光带到关键处（跳转到某步后的单次脉冲）。

### 3.2 时长与缓动的三档制

| 档 | 时长 | 缓动 | 用途 |
|---|---|---|---|
| 快 | 150ms | ease-out | 悬停反馈、按钮态、toast 出现 |
| 中 | 300ms | ease-in-out | 展开/收起、抽屉、布局推挤 |
| 慢 | 600ms | ease-in-out | 一次性叙事入场（首屏切片概率条），一屏至多一次 |

- 禁止 spring/弹跳：仪器的指针不弹跳——弹跳传递「玩具感」，与品牌人格冲突。
  （若未来某处确需物理感，须修订本条并写明理由。）
- 禁止 >600ms 的任何 UI 动效；数据本身的时间（生成过程回放速度）不算 UI 动效，
  它是被观察对象，速度可由用户控制。
- Reduced-motion 尊重系统设置：叙事入场降级为直接呈现。

### 3.3 何时禁止动画

- 数字更新：读数直接变，不滚动翻牌——翻牌是老虎机语言，不是仪表语言。
- 错误与失败态：立即、静止地呈现，失败不需要转场。
- 高频重复区（列表每行）：入场动画一律禁止，只有整表首次呈现可用一次。

### 3.4 Three.js 场景的运动纪律

- 相机运动只响应用户输入或跟随当前步——没有「自动巡航炫技」。
- 数据点的运动=数据的变化；装饰性粒子、呼吸光效禁止（观察室没有氛围灯）。
- 三维与二维联动锚定同一当前步：二维步进，三维同步——两个视图是同一仪器的两块表盘。

## 第四章 · 视觉规格数值（Design Tokens 的宪法值）

> Volume II 定哲学，本章定数字。实现时 token 化（对应 DS0），改值=修订本章。

- **网格**：12 列；内容主栏 680px（阅读）/ 760px（含侧注）；数据可视化可全宽。
- **间距阶**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（8pt 制 + 半步 4）。
- **圆角阶**：8（小控件）/ 16（卡片）/ full（胶囊与主 CTA）。三级之外禁止。
- **字号阶**（7 级）：11（角标）/ 12（辅助）/ 12.5（正文次）/ 13.5（正文）/ 15（小标）/ 18（节标）/ 26（页标）。
- **动效阶**：150 / 300 / 600ms（见 Motion Bible）。
- **语义色**（≤5，含义恒定）：accent（主动作与当前步）、琥珀（官方引用）、
  翠绿（本机实测）、红（异常/退化/失败）、金（最值高亮）。
- **数字排版**：等宽 + tabular-nums + 右对齐 + 单位常驻，无一例外。
- **焦点环**：所有可交互元素统一 2px accent 外环（键盘可达性是仪器的操作安全）。

## 第五章 · 图标执行规范（承接 Volume II 图标哲学）

- 单库制。候选：Hugeicons（线条统一、覆盖广、含 animated 变体、免费集可用性已核实）。
  启用前置条件：对我们的语义清单（播放/步进/分岔/对比/重放/熵/规则/导出/导入/
  seed/温度/窗口/设备……约 40 个）做覆盖盘点，覆盖 ≥90% 即定为唯一库；
  缺口按同规格自绘补齐并入库管理，仍视为单库。
- 规格：24 viewBox、1.5px stroke、round cap/join；渲染尺寸 16（行内）/ 20（按钮）/ 24（导航）。
- Outline=可用，Filled=选中（Volume II 3.3 唯一规则）。
- 迁移纪律：一次批次内完成映射表迁移，禁止新旧双轨长期并存。

## 第六章 · 触屏与响应式语法

- 手机=完整的「读」（回放、双结局、报告、成绩单），复杂「做」诚实引导桌面（P19）。
- 触target ≥44px；悬停语法在触屏自动降级为「点击第一次=预告，第二次=进入」或直接进入。
- 断点哲学：内容决定断点（主栏 680px 放不下时切换），不按设备型号硬编码。
- 三维场景在手机默认折叠为入口卡，注明性能与操作两个真实原因（P12）。

## 第七章 · 执行与守护

- 新功能交互评审四问：用的是哪条既有语法？新造了什么？为什么现有语言不够？五年后成立吗？
- 违例三来源自查：赶工期（最常见）、参考了不相干产品的惯例、误把装饰当解释。
- 本卷与宪法冲突时，宪法优先；数值规格与哲学冲突时，哲学优先、数值修订。
