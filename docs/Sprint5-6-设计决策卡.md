# 设计决策卡 · Sprint 5–6「此刻卡片 + 内心独白剧场 + 思考字幕」

> 目标：治「柱子在跑但看不懂」——首屏默认就能一眼看懂 AI 在工作、在干什么。
> 铁律：看懂优先于酷炫；每个画面能用一句人话回答「这在告诉你什么」。

## 决策 1 · 此刻卡（MomentCard）

- **问题**：概率柱在跑，用户不知道此刻发生了什么。
- **方案**：玻璃卡浮在概率柱区右上（Focus Lens 未展开时占用同一位置，二者互斥不叠加），三行人话：确定度 / 候选 / 节奏。
- **字段依据**（`lib/momentCard.ts`，全部有测试）：
  - 确定度分档：top-1 概率 ≥0.8 高 / ≥0.4 中 / 其余低（与 `explainStep` 的 0.8 高集中口径一致）；四格量条 = ceil(prob×4)。
  - 「前两名几乎并列」当且仅当 top-1 − top-2 < 0.05（与 `closeSteps` 犹豫口径一致）。
  - 节奏 = 当步 dt ÷ 全程 dt 中位数，≥2 倍才说「变慢——它在难点上」；无 dt 记录时该行诚实缺席。
- **不做**：不用「思考中/纠结中」等无字段依据的拟人措辞。

## 决策 2 · 思考字幕（ThinkingCaption）

- **问题**：需要一条随播放实时更新的「人话翻译」，正文仍是主角。
- **方案**：底部电影字幕条（青绿小标签「思考字幕 · LIVE」+ 暖白正文 + 等宽元数据行 step/熵/top-2 差距）。
- **模板触发条件**（`lib/thinkingCaption.ts`，全部有测试）：温度 0→贪心；差距 <2%→「一次抽签决定走向」；rank>1→「温度让它没选第一名（真实 rank）」；top-1 ≥90%→「几乎没有悬念」；差距 <5%→「它在 A 和 B 之间犹豫」；否则通用竞争句。所有数值实算。
- **与此刻卡同源**：并列/犹豫阈值同一常量口径，两处读数必然一致。
- **位置约束**：Replay 暂停时底部引导卡（章节停点/先猜后验）在说话，字幕只在 playing/done 出现，不叠加。

## 决策 3 · 内心独白 · 活动日志（ActivityLog）

- **问题**：播放过程中没有「已经发生了什么关键时刻」的账本。
- **方案**：左栏时间轴（窄容器隐藏防遮挡），复用 `lib/decisionPoints` 口径（首字/最高熵步/犹豫点），只列 index ≤ 当前步的时刻（「live 感」：时刻是到达后才出现的），点击跳转该步。
- **不做**：不新造第二套「关键时刻」算法（NRP）；无时间戳字段不显示假时刻。

## 覆盖范围

- 首屏 Replay（demo）与实时生成（running）都挂载此刻卡+字幕；活动日志挂 Replay（实时生成的 decisionPoints 每步重算成本高，且 done 后 ObservationSummary 已有决策时刻 chips）。
- 分岔视图（forkView）不挂载：该视图有自己的对照叙事，避免读数歧义。

`npx tsc -b` / `npm run lint` / `npx vitest run`（244 通过，其中新增 10）/ `npm run build` 全绿；本机 dev 实测首屏 Replay：此刻卡、字幕、活动日志随步实时更新，数值与 trace 一致。
