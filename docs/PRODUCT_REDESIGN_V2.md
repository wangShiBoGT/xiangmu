## 核心洞察：人为什么能发现幻觉？

通过分析 104 个真实幻觉案例，我们发现人类发现幻觉的方式有且只有以下几种：

### 1. 查外部资料（External Verification）
- **案例**：编造的学术论文 → 去 Google Scholar 查 → 不存在
- **案例**：甘地名言 → 查甘地语录合集 → 找不到原文
- **案例**：Alabama 边界 → 查地图 → Mississippi 最长

### 2. 逻辑检查（Logic Check）
- **案例**：孩子身高 8ft → 物理不可能（比姚明还高）
- **案例**：兔子无限繁殖 → 资源限制会阻止指数增长
- **案例**：跑步速度变负数 → 数学上荒谬

### 3. 常识判断（Common Sense）
- **案例**：Monopoly Man 单片眼镜 → 官方图片一看就知道没有
- **案例**：月球第一句话 → 稍微了解历史的人都知道
- **案例**：8ft 的 12 岁孩子 → 一听就不对

### 4. 多次验证（Consistency Check）
- **案例**："第三个词是 dog" → 逐词数一遍 → 发现不是
- **案例**：同一问题问多次 → 答案不一致 → 说明模型不确定

### 5. 专业知识（Domain Expertise）
- **案例**：错误的数学证明 → 数学家一眼看出逻辑漏洞
- **案例**：格式塔心理学证明战争 → 心理学家知道完全不相关
- **案例**：迭代期望定理证明高斯分布 → 统计学家知道用错定理

---

## 关键结论

### ❌ 我们的工具做不到的：
1. **判断事实真假**：我们没有外部知识库
2. **逻辑推理**：我们无法判断"8ft 的孩子"不合理
3. **常识判断**：我们不知道 Monopoly Man 长什么样
4. **专业验证**：我们不是数学家，看不出证明错误

### ✅ 我们的工具能做到的：
1. **标记需要核实的内容**：数字、日期、引用、专有名词
2. **检测多次运行的一致性**：同一问题多次生成，对比差异
3. **提取原子主张**：把长文本拆解成可验证的独立陈述
4. **追溯来源**：如果用 RAG，标记每句话来自哪个文档
5. **辅助人工审计**：提供结构化的审计界面，不是给结论

## 目标用户

### 主要用户
**科研机构用 AI 辅助整理文献的人**

**场景**：
1. 用户上传 20 篇论文 PDF
2. 用户问："总结这些论文中关于 transformer attention 机制的创新点"
3. AI 生成 3 页摘要
4. 用户需要判断：这份摘要能不能用于写综述？

**痛点**：
- 摘要中可能编造论文结论
- 可能张冠李戴（把 A 论文的结论说成 B 论文的）
- 可能误解术语（把 "self-attention" 和 "cross-attention" 混淆）
- 用户需要逐句核对原文，但 20 篇论文太多

**我们的价值**：
- 标记摘要中每句话来自哪篇论文（RAG 溯源）
- 标记未找到来源的陈述（可能是编造）
- 多次生成对比，标记不一致的陈述
- 提供"逐句核对"界面，点击跳转到原文

### 次要用户
- 金融分析师：用 AI 生成研报，需要核实数据
- 法律助理：用 AI 整理案例，需要核实法条引用
- 医疗研究员：用 AI 总结临床试验，需要核实数据

## 第一版功能设计（MVP）

### 核心流程

```
用户上传文献 PDF
    ↓
用户输入研究问题
    ↓
系统调用 LLM 生成 3-5 次（固定 seed，只改 temperature）
    ↓
提取每次生成的原子主张（atomic claims）
    ↓
对比一致性：
  - 完全一致 → 绿色（模型确信）
  - 部分一致 → 黄色（模型有分歧）
  - 完全不同 → 红色（模型高度不确定）
    ↓
RAG 溯源：
  - 在上传文献中检索每条主张
  - 找到来源 → 标记来源段落
  - 未找到来源 → 标记"无来源"
    ↓
标记风险点：
  - 数字（特别是低熵数字）
  - 日期
  - 论文引用格式
  - 专有名词
    ↓
生成审计报告：
  - 一致性分析
  - 来源追溯表
  - 风险点列表
  - 人工核对界面
```

### 1. 原子主张提取（Atomic Claim Extraction）

**方法**：使用 LLM 自身提取

```typescript
// 伪代码
async function extractAtomicClaims(fullText: string): Promise<string[]> {
  const prompt = `
请将以下文本拆解为独立的、可验证的原子主张（atomic claims）。

规则：
1. 每条主张应该是一个完整的陈述
2. 每条主张应该可以独立验证真假
3. 不要遗漏任何信息
4. 不要添加原文没有的内容

输入文本：
${fullText}

输出格式（JSON）：
{
  "claims": [
    "主张1",
    "主张2",
    ...
  ]
}
  `;
  
  const response = await llm.generate(prompt);
  return JSON.parse(response).claims;
}
```
