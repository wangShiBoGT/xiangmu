## 定位声明（评审 V1 补）

> 别人做 **AI Story**（拟人化讲故事），我们做 **AI Evidence**（可核验证据）。
> 壁垒 = Evidence First 方法论 × 全本地零成本推理 × `.aitrace` 可复现格式。
> 真正的竞争对手不是其他可视化工具，而是用户「AI 就是一个聊天框」的固有认知。

## 第 1 层 · V1 首屏叙事（下一个开发批次）

| 锚点 | 内容 | 验收标准 | 状态 |
|---|---|---|---|
| **A1** | 首屏第一层（谜题句）：「为什么同一句问题，AI 每次回答都不一样？」 | 无术语；锚在用户既有经验 | 📋 |
| **A2** | 首屏第二层（谜底句）：「因为这个答案，曾经差点变成另一个答案。」 | 可被 A3 切片直接证明 | 📋 |
| **A3** | 首屏犹豫点静态切片：真实 trace 步 68「本身 20.08% ── 这个词 20.08% ── 其余所有候选合计 59.84%」 | 数据来自 demo.aitrace 真实记录，可点开原始 top-k；必须含其余候选合计行，不制造二选一错觉（评审 R1） | 📋 |
| **A4** | 首屏按钮：「亲眼看这一刻 →」承诺：看到那个差点分岔的瞬间；兑现：演示直达犹豫点暂停帧（≤10 秒） | P4 成立；演示资源预加载或首帧兜底，超时复用 BreathingWait 真实等待说明（评审 V4） | 📋 |
| **A5** | 演示暂停帧解释层（第一次出现机制解释）：「AI 并不是先想好整句话。它会在每一步，从多个候选中按概率采样。」此处首次引出 温度/seed/掷硬币隐喻 | 首屏之后才出现术语（P3） | 📋 |
| **A6** | 演示收束语改为真实统计版：「这个回答共 229 步，其中 15 步前两名概率差不足 5%——它有 15 次差点变成另一个答案。」 | 每个数字可点开对应步；交付「按差距排序的 15 瞬间跳转列表」（评审 R3）；附「换个 seed 再跑一次并排对比」出口复用 CompareView，兑现首屏谜题句闭环（评审 R2） | 📋 |
| **A7** | 技术卖点卡片（模型/WebGPU/本地）移出首屏第一层，下移或收进第二屏 | 首屏第一层无技术规格 | 📋 |
| **A8** | 首次访问行为 trace（匿名、本地）：首点时间、先滚动/先点、是否看到犹豫点、是否点候选——作为 P0-3 KPI 的测量仪 | 不上传、可关闭、口径写明；设备页展示本机首访漏斗，度量自己看得见才算闭环（评审 B4） | 📋 |
| **A9** | 10 人陌生用户测试（录像观察行为，不只问答；四问：这是干什么的/为什么点/一句话介绍/你觉得接下来会发生什么）。批次 1 上线后一周内执行；不达标只迭代 A1–A4 文案层不推翻结构，迭代同样走锚点变更规约（评审 B2） | ≥7 人正确理解才算首屏达标 | 🔨（用户执行） |
| **A10** | 首屏切片与全部统计数字运行时从 demo trace 实时计算，禁止硬编码；更换 demo trace 时文案零成本自适应（评审 B3，消除单 trace 依赖） | 换 trace 后无需改代码文案仍正确 | 📋 |

## 开发顺序（当前共识）

```
批次 1（📋 已定稿，估量 M，无前置依赖）：A1–A8 + A10（首屏叙事 + 暂停帧 + 收束语 + 15 瞬间跳转 + 行为 trace）
批次 1.5（用户执行）：A9 陆人测试，不达标回到 A1–A4 文案迭代
批次 2（估量 M，依赖批次 1 的可展开陈述组件）：C1–C2（全站 Evidence First 改造）
批次 3（估量 L）：C3（犹豫点双结局）→ D3/D4（行为 Benchmark 与规则包）
批次 4（估量 M）：D1/D2 扩展（官方引用层 + 系统 Benchmark 完整化）
远期：D5/D6、E1–E4、F1
（S ≈ 半天内，M ≈ 1–3 天，L ≈ 一周量级；仅供排序，不作承诺）
```
