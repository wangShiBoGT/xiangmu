# 样式修复总结 - 2026-08-04

## 问题回顾

用户反馈的核心问题：
1. **浮层遮挡问题**：底部输入卡片会遮挡 3D 图表中的元素
2. **中间空白问题**：3D 图表和下方内容之间有大片空白
3. **透明度问题**：左侧"关键时刻"面板半透明，和背景重叠看不清

## 已完成的修复

### 1. 中间空白区域修复 (Commit: 861d675)

**问题根因**：
- 给固定高度容器 `h-[min(68vh,720px)]` 添加了 `pb-40` (160px)
- 导致内部内容被压缩，容器底部留出大片空白

**解决方案**：
- 移除所有容器的 `pb-40`
- 调整底部绝对定位元素的 `bottom` 值，避开输入框遮挡

**修改细节**：
- InstrumentCluster.tsx：移除容器 `pb-40`，调整 3 个底部元素
  - 坐标图例：`bottom-3` → `bottom-44`
  - "第X步最分散"按钮：`bottom-14` → `bottom-52`
  - hover 信息条：`bottom-3` → `bottom-44`

- ObservePage.tsx：移除容器 `pb-40`，调整 6 个底部元素
  - 思考字幕：`bottom-8/4/1` → `bottom-44/52`
  - 演示注释：`bottom-14` → `bottom-52`
  - 动作栏：`bottom-2` → `bottom-44`
  - 播放控制条：保持 `bottom-44`（之前已修改）

### 2. 浮层透明度修复 (Commit: df462c4)

**问题根因**：
- 使用了项目中不存在的 CSS 类：`bg-bg-float`、`border-border`、`shadow-[var(--shadow-tooltip)]`
- 这些 CSS 变量未定义，导致背景透明度不正确

**解决方案**：
- 统一替换为项目实际使用的颜色系统
  - `bg-bg-float` → `bg-obs-2` (完全不透明)
  - `border-border` → `border-obs-line`
  - `shadow-[var(--shadow-tooltip)]` → `shadow-float`

**修改组件**：
- ActivityLog.tsx (关键时刻面板)
- MomentCard.tsx (此刻卡)
- SentenceRibbon.tsx (句子带)
- TeamFlow.tsx (团队流)
- AgentTimeline.tsx (Agent 时间线)
- ObservationSummary.tsx (观测总结)

## 设计原则总结

### 响应式适配原则

1. **固定高度容器不加 padding**
   - ❌ 错误：`<div className="h-[600px] pb-40">`
   - ✅ 正确：`<div className="h-[600px]">`
   
2. **绝对定位元素避开底部固定区域**
   - 输入卡片高度约 160-200px
   - 底部元素应使用 `bottom-44` (176px) 或 `bottom-52` (208px)

3. **使用项目现有的颜色系统**
   - 不透明背景：`bg-obs-2`
   - 半透明背景：`bg-obs-2/85` 或 `bg-obs-2/95`
   - 边框：`border-obs-line`
   - 阴影：`shadow-float`

### 屏幕适配检查清单

✅ 3D 图表容器高度响应式：`h-[min(68vh,720px)]`
✅ 底部元素避开固定输入框
✅ 浮层背景不透明
✅ 文字可读性良好
✅ 无内容重叠
