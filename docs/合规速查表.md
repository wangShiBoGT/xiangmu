> 用途：日常写代码/文案只对照本表，不再通读四卷宪法（省 token）。

> 冲突裁决：基本法(P1–P4/哲学/语法) > 通则(P5–P31) > 各卷规范 > 个人品味。

> 三层级：价值层(P1/P9/P25/P26/使命句) · 认知层(P27/P28/P29) · 交互层(P30/P31+既有交互通则)；新原则归不进不新增。

## 0. 每次提交前 6 项自查（宪法自查模板）
1. **文案过词表**：无禁词（见 §1），拟人词只作索引名（点开即证据 + 不在谓语位）。
2. **数字合规**：每个数字带单位+口径+来源；等宽 tabular-nums 右对齐；无「约/估计/大概」。
3. **Token 合规**：间距/圆角/字号/动效/颜色都在档内（见 §3）；无档外值。
4. **五段式**：改动的页面满足 Question→Evidence→Interaction→Conclusion(用户产生)→Replay。
5. **来源分层**：官方引用(琥珀) 与 本机实测(翠绿) 永不同表不同色，卡角带 Badge。
6. **组件七态**：默认/悬停/按下/聚焦/禁用/空态/失败态齐全；空态有唯一下一步。

## 1. AI 语言宪章（文案白/黑名单）
**禁**：AI 想 / 认为 / 决定 / 理解 / 意识到 / 改变主意 / 偏好 / 记得 / 忘了；思考中… / 正在理解你的问题…；聪明 / 强大 / 有灵魂 / 像人一样。
**允**：Token 候选 概率 分布 熵 采样 温度 Seed / Trace Replay 分岔 上下文 窗口 / 生成 输出 命中 衰减 延迟 吞吐 / 犹豫点*、差点*（*仅当可点开到概率差证据）。
**改写范式**：
- AI 犹豫了 → 这一步，前两个候选概率仅差 X%
- AI 改变主意 → 换一个 seed，这一步采样到了另一个候选
- AI 在思考 → 正在生成第 N 个 token（每 token 平均 X ms）
- AI 理解上下文 → 这 N 个 token 都在当前上下文窗口内
- AI 忘了前文 → 该内容已超出上下文窗口（第 N token 之前）
回卷：VolI 第三章。

## 2. 31 条原则（一行速记；P1–P4 不可修订）
- **P1 证据优先**：任何陈述句可点开到原始数据+来源。
- **P2 展示非断言**：删掉解释文字，证据仍支撑同结论。
- **P3 好奇先于解释**：入口页只提问；名词解释在现象之后。
- **P4 每次点击赚下一次**：按钮写得出「承诺什么/下屏怎么兑现」。
- P5 科学仪器（语言来自实验室非营销页）｜P6 无装饰（动效必须解释AI）｜P7 不伪造智能（无真数据不展示内部状态）｜P8 可重放（seed/参数/trace 齐全，逐token复现）｜P9 诚实缺席（测不到=空态，不估算）｜P10 分层披露（结论→证据→原始，自愿下潜）｜P11 每屏唯一主动作（3秒能指出点哪）｜P12 仪器不谎报自身（每测量视图有「本测量不包含什么」）｜P13 拟人词只作索引｜P14 来源永远分离（不同表不同色带来源标）｜P15 用户下结论｜P16 等待即教学（无假进度）｜P17 数字必带单位与口径｜P18 一致性高于新鲜（同语义同组件同图标，先复用）｜P19 手机读/桌面做（无横向溢出、无不可达按钮）｜P20 慢即是稳（宁空态不凑数）｜P21 Trace即产品（格式向后兼容永不破坏）｜P22 本地优先隐私恒定（断网可用、无遥测）｜P23 失败也是数据（退化与成功同等呈现）｜P24 五年检验（依赖当前模型特性的决策单独标注失效条件）｜**P25 每一个像素都来自真实推理**（无装饰动画，所有视觉变化由 trace 真实字段驱动；大场面只给真实犹豫点，一直爆=没有爆）｜**P26 先看到意义再看到数据**（可视化对象是 Decision 不是孤立变量；人话先行、指标下潜；四问检验：这是什么/为何出现/AI 在发生什么/用户获得什么理解，答不全=装饰删除）｜**P27 认知优先**（先呈现可观察证据再帮助理解；Evidence→Pattern→Meaning→Explanation 可选，禁倒序；五问：不写一句解释用户能不能自己看懂）｜**P28 一屏一问**（一屏只回答一个问题，其余信息默认下潜）｜**P29 先模式后数字**（先形状/对比/变化，数字只在 tooltip/下潜层）｜**P30 统一视觉语法**（全部动画/交互归入 Birth/Branch/Collapse/Flow 四语法之一）｜**P31 问题驱动导航**（导航/侧栏/入口按用户问题组织；界面用「时刻」，专业层 Decision Moment，代码 Decision）。
回卷：VolI 第二章。

## 3. Design Token 宪法值（DS0 目标）
- **间距**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（8pt + 半步4）。
- **圆角**：三级制 8(小控件) / 16(卡片) / full(胶囊+主CTA)。〔DS0 迁移待按现状主力档校准，见 §6 W-2〕
- **字号**（7级）：11(角标)/12(辅助)/12.5(正文次)/13.5(正文)/15(小标)/18(节标)/26(页标)。〔见 §6 W-3〕
- **动效**：150ms ease-out(悬停/按钮/toast) / 300ms ease-in-out(展开/抽屉/推挤) / 600ms ease-in-out(一次性叙事入场，一屏≤1次)。
- **语义色 ≤5**：accent(主动作+当前步) / 琥珀(官方引用) / 翠绿(本机实测) / 红(异常·退化·失败) / 金(最值高亮)。中性色不限；渐变禁用于信息表达。
- **数字排版**：等宽 + tabular-nums + 右对齐 + 单位常驻，无例外。
- **焦点环**：所有可交互元素 2px accent 外环。
- **阴影**：仅表达浮起层级(弹层/抽屉)，平面内容零阴影。
- **主栏**：680px(阅读)/760px(含侧注)；数据可视化可全宽；12列栅格。
**动效红线**：禁 spring/弹跳；禁 >600ms UI动效；数字更新直接变不翻牌；错误/失败态立即静止呈现；列表每行禁入场动画(整表首次可一次)；Three.js 无自动巡航、无装饰粒子/呼吸光。Reduced-motion 降级为直接呈现。
回卷：VolIII 第三、四章。

## 4. 图标规范（DS1）
- **单库制**（候选 Hugeicons；缺口同规格自绘仍算单库）。规格：24 viewBox、1.5px stroke、round cap/join。渲染 16(行内)/20(按钮)/24(导航)。
- **Outline=可用/未选中，Filled=当前/选中**（唯一规则）。
- 图标是字体不是插画；语义唯一(一动作一图标)；文字能说清不放图标；图标不下价值判断(✓/✗ 只用于布尔事实)。
回卷：VolII 第三章 / VolIII 第五章。

## 5. 交互语法与组件红线
- **五段式**：Question→Evidence→Interaction→Conclusion(用户产生)→Replay/Next。缺Question=Dashboard违宪；缺Evidence=营销页违P1；缺Interaction=Demo违1.5；替用户下结论违P15；不可Replay违P8。
- **下潜三级**（唯一实现）：①陈述句(虚线下划线+⌄)原位展开 → ②证据卡(数据+来源路径行) → ③原始层(trace/JSON)。永远原位展开或右侧抽屉，**不跳页**；推挤动画≤300ms；每级有显式收起。禁新造弹窗/新页面模式。
- **时间语法动词**（全站唯一）：播放/暂停(空格) 步进(←/→) 跳转(点列表行+到达脉冲) 分岔(不破坏原trace) 对比(同源对齐) 重放(同seed逐token一致)。Agent 事件也是时间轴上的「步」，不新造动词。
- **悬停**=预告(轻量提示,150ms出现,离开即销毁,内容不可再交互)；**点击**=承诺。悬停信息触屏须可达。
- **组件何时禁**：热图无真数据禁(attention红线)；跨模型token级对齐禁(只做统计级对比)；一卡混两来源禁；Inspector套Inspector禁(走三级下潜)；深度>3的树直接展示禁；核心内容放抽屉禁。
- **Toast**：单条3秒可含一动作；禁堆叠、禁承载错误详情(错误走失败态)。
回卷：VolIII 第一、二章。

## 6. Benchmark / 分数纪律
- **五证齐全**才算「分数」：①来源(官方引用/系统实测/行为统计三选一，永远标) ②口径(测了/没测什么+单位) ③条件(模型/设备/参数/上下文) ④分布(中位数+极差；单点须自声明) ⑤复现路径。缺一降级为「读数」(不参与比较)或不显示。
- **三层永不同表**：官方引用(琥珀·只是转述·永不与本机同表) / 系统测量(翠绿·延迟吞吐衰减) / 行为统计(翠绿·犹豫步占比/命中率/结局分布，可同页但每卡单一来源)。
- **统计纪律**：分布优先(不给单值/均值)；最小样本(延迟分位≥8、衰减≥32、行为≥2run)不足则「无法测量」；异常不悄剔；不做显著性断言(只陈列分布)；带核实日期/测量时间。
- **永不引入**：综合大数字/跨用户排行榜/聪明指数/无法当面复现的分数。
回卷：VolIV（全卷较短，需要时整读）。

## 7. 品牌语气
短句、陈述、不感叹、不推销；幽默须来自事实本身。参照物=天文台/实验室，非发布会/预告片。暗色=观察室、亮色=报告纸（场所切换非主题切换，不许打破）。
**永不学**：logo墙/用户数大字报、赛博朋克终端绿、骨架屏假加载、无限滚动feed、弹窗NPS、AI插画风装饰图。
回卷：VolI 第四章 / VolII 第五章。
