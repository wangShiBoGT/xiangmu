# ACDL 07 · Layout（一屏一问 · P28）

> 任何一屏在任何时刻只回答一个问题；其余信息都是答案的支撑，默认下潜。评审固定一问：「这一屏，到底回答哪个问题？」答不出或多于一个 = 重新分层。

## 1. 屏 → 唯一问题（验收口径）

| 屏 | 唯一问题 | 主舞台内容（五层链顺序） |
|---|---|---|
| 生成中（实况） | AI 现在为什么写这个？ | 正文（Birth）+ 当前时刻 Pattern（近等高条等）+ 一条细状态线 |
| 完成态复盘 | AI 哪里最犹豫？ | 正文 + 关键时刻（Story 列表）+ 思路地图 |
| RAG 舞台 | AI 为什么引用这一段？ | 文档 Flow + 命中/弃用 |
| Agent 规划 | AI 为什么决定这样做？ | 计划 Flow + 交棒 |
| 采样显微镜（下潜） | 换个温度它会写什么？ | 反事实 Collapse |
| 概率地形（下潜） | 整条路径的地形长什么样？ | Decision Ocean（Feel） |
| 对比 | 两次运行从哪里分岔？ | 双正文 Branch |

## 2. 运行中一屏的收纳（反面案例 A 的解法）

默认在场：主叙事区（正文+当前 Pattern）+ 一条细状态线（阶段+速度）。
默认下潜：Debug、Pipeline 卡、Sampling Inspector、采样显微镜、此刻卡、3D——右侧图标列/「专业视图」开关，点开才占屏；专业面板一个不删，但**永不同时全部在场**。

## 3. 层级秩序

- 主舞台（Understand，2D）＞ 背景（Feel，3D/粒子）＞ 下潜面板（Professional）；
- 弹层永远压暗背景一层，禁止系统原生弹层（06 §3）；
- 三态骨架：运行中 / 完成汇总 / 慢速回放，切换不丢信息。

## 4. 违宪判例

创始人截图（2026-07-25）：生成中一屏同时在场 Debug 条、五段流水线、此刻卡、Inspector、采样显微镜、3D 柱林——同屏回答七个问题，判违宪，作为永久反面案例引用。
