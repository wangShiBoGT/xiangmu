# ACDL 05 · Pattern（先模式后数字 · P29 / Layer 2）

> 大脑识别形状、对比、变化，不阅读数字。以后不要直接画数字，先画 Pattern；数字只是 tooltip。

## 1. 定义

Pattern = 无需读任何数字就能被眼睛识别的形状差异。

反例（Data）：`形成 25.7% · 看起来 25.6%`、`Entropy 2.43 nats`
正例（Pattern）：

```text
形成    ██████████
看起来  █████████▉   ← 两根几乎一样高，用户自己说「哦，差一点」
```

```text
犹豫步：  ▃▃▃▃▃▃▃▃      所有候选差不多高
确定步：  █▁▁▁▁▁▁▁      一根独大
```

## 2. 字段 → Pattern 映射表（全站统一，禁止另造）

| 字段 | Pattern（先看到） | 数字（tooltip/下潜） |
|---|---|---|
| top-2 gap 小 | 两根近等高条并置摇摆 | gap % |
| 选中 rank>1 | rank1 长条 vs 被抽中短条 + 抽签动线 | rank/T/seed |
| entropy 高 | 多根均匀矮条（vs 邻步一根独大对比） | H nats |
| dt 异常 | 节奏轨上的凸起 | ms/倍数 |
| prob（正文） | 把握度着色深浅 | P 值 |
| 检索命中/弃用 | 实线亮卡流入 vs 虚线暗卡停驻 | score/耗时 |
| 分岔 | 两条正文并行到分岔点岔开 | 首分歧步号 |

## 3. 规则

- 每个 Pattern 必配对比锚（几乎等高需要「正常步长这样」的参照，单独一根条没有意义）；
- Pattern 必须由真实字段确定性生成；
- 数字永不默认在场：hover/点开才出现；
- Pattern 归属四语法之一（近等高条摇摆→Branch 前奏；胜者落下→Collapse）。
