# Observe 页融合重构方案（先方案后代码）

> 依据：AI_DESIGN_CONSTITUTION → design-language.md → design-system.md → component-guideline.md → layout-plan.md → remove-plan.md → reference-study.md → E5-VolumeI 产品宪法。
> 针对截图暴露的问题：不是"圆角太圆"，是**信息没有融合成一台仪器**——它现在是"一堆各自为政的浮块"。

---

## 一、诊断：为什么这一屏一眼看出是 AI 拼的

对照截图逐区域，与文档判据一一对应：

| 截图区域 | 现状 | 违反的条款 |
|---|---|---|
| ① DEBUG 条（Back/Step/Continue/New Seed/断点）置顶第一屏 | 调试工具压在观察对象之上 | layout-plan：Debug 永远在**最底**；宪法 P11 每屏唯一主动作 |
| ② 阶段链：8 个带对勾的方块 + 箭头，折成 3 行 | 「一事一卡」+ 箭头连线，是流程图贴纸不是测量记录 | design-language P4「对齐优先于卡片」；guideline「卡不套卡」 |
| ③ 右栏 PIPELINE 进度条 | 和 ② 表达**同一份数据**（tokenize/prefill/decode 耗时），同屏两遍 | remove-plan §8 重复统计：同一读数只渲染一处 |
| ④ 「专业视图 开／熵热力 关／概率地形／更多」四个大方块按钮 | 视图开关做成了并列大按钮，还各自换行 | guideline §4 Tabs：**不用胶囊分段控件、不用卡片式 tab**——开关=文字+底部指示线 |
| ⑤ 对比实验一行：说明句 + 3 个 chip 按钮悬在 composer 上方 | 操作散落在内容中间 | layout-plan：控制集中在 Interaction 带，不穿插 |
| ⑥ composer 内 chips（Qwen3·WebGPU·T0.6 / 联网检索 / Agent 规划 / 规划:DeepSeek-R1） | 五种 chip 形态混排，槽位不固定 | guideline §3 Badge 唯一实现；reference-study「槽位固定」 |
| ⑦ 右栏 THROUGHPUT / ENTROPY / 最后一步的候选 | 方向正确（DevTools 右栏），但每块是独立卡，标签/读数/曲线格式不一 | guideline 法则二：丝印 + 等宽读数 + 统一解剖 |
| ⑧ 整屏 | 中间大片空、块与块靠留白隔开、没有对齐线 | reference-study 机制 3「密度配秩序」：高级感来自**槽位固定+对齐**，不是来自留白 |

一句话：**每个信息都对，但它们互相不认识。** 高级感的来源（DevTools/Stripe/Linear 的共性）是骨架恒定、槽位固定、重复归一——这一屏三条全违反。

## 二、目标骨架：一台仪器，四个恒定区

参照系权重（reference-study 结论）：DevTools 骨架 > Stripe 数字纪律 > Linear 灰度层级。Observe 页骨架收敛为**四区恒定**，任何新功能服从骨架：

```text
┌─────────────────────────────────────────────┬──────────────┐
│ ① 工具行（28px，一行，永不换行）               │              │
│    左：运行标识（模型·设备·step 计数）          │  ④ 仪表栏     │
│    右：镜头开关 Tabs（专业视图|熵热力|概率地形…）│   （Gauge 列）│
├─────────────────────────────────────────────┤  THROUGHPUT  │
│ ② 标本区（Hero，唯一视觉中心）                 │  ENTROPY     │
│    Prompt → 答案正文（把握度着色）             │  候选 Top-k  │
│                                             │  （选中联动） │
├─────────────────────────────────────────────┤              │
│ ③ 记录轴（Trace rail，单行）                  │              │
│    流水线时间轴：一条横轴，段宽=真实耗时         │              │
│    tokenize│prefill│decode│tool│……           │              │
├─────────────────────────────────────────────┴──────────────┤
│ ⑤ 操作台（Bench）：对比芯片 + composer + 开始记录            │
├─────────────────────────────────────────────────────────────┤
│ ⑥ Debug 带（仅专业视图，最底）：Back/Step/Continue/断点      │
└─────────────────────────────────────────────────────────────┘
```

核心融合动作（不是删，是**归一**）：

### 1. 阶段链 ②＋右栏 PIPELINE ③ → 一条「流水线时间轴」（TraceBand）
- 8 个方块+箭头改为**一条水平轴**：每段宽度 ∝ 真实耗时（33ms/1.2s/25.7s/51.4s…），段内丝印标签 + 等宽耗时，hover 展开该段决策（保留现有"点击步区间看阶段决策"能力）。
- 这就是 DevTools Network waterfall 的语法：**时间本身成为布局**，箭头/对勾/方块全部消失——完成态用明度表示，不需要 ✓。
- 右栏 PIPELINE 卡删除（remove-plan §8），数据只在这一条轴上。

### 2. 四个大方块开关 ④ → 工具行右端 Tabs
- 「专业视图/熵热力/概率地形/更多」改为一行文字开关：开=ink 字重 500 + 2px measure 底线，关=ink-2。高度 28px，永不换行。
- DEBUG 条从顶部下沉到页面最底（layout-plan 原判），且仅专业视图渲染——普通观察者第一屏看到的是**答案与轴**，不是调试器。

### 3. 右栏 ⑦ → 统一 Gauge 解剖
- 每个仪表统一四层：丝印（`THROUGHPUT · 本机实测`）→ 大读数（等宽+tabular-nums+单位）→ 细线迷你图（无渐变填充）→ 可选 micro 脚注。
- 「最后一步的候选」升级为**选择联动 Inspector**（Figma/DevTools 机制）：选中正文任一 token，右栏即显示该步 top-k 概率条——右栏从"陈列"变"联动"，这是本方案最大的体验增益。

### 4. composer ⑥ → Bench 槽位固定
- 状态行一次成型：`模型 · 设备 · T · 检索 · 规划`固定五槽位，全部用统一 Badge（同高、同字号、等宽读数），不再三种形态混排。
- 对比实验 chips ⑤ 移入 Bench 区内部（composer 上沿），说明句删去（remove-plan §3：教育性长句首次展示一次即可）。

### 5. 全屏对齐纪律
- 左栏（①②③⑤⑥）与右栏（④）各自一条左对齐线贯穿到底；所有耗时/百分比右对齐；卡间距只用 8pt 序列。
- 中性色占 95%，语义重量只留：measure（当前步/选中）、caution（高熵）、alert（失败）——完成态的 ✓ 全部退场（成功=中性，宪法：成功不需要绿色徽章）。

## 三、为什么这样"更高级大气"（机制，不是审美偏好）

1. **时间轴替代流程图**：耗时成为宽度，用户一眼读出"25.7s 都花在 decode"——信息量升，元素数降（8 块 16 边 7 箭头 → 1 条轴）。这就是 Tufte 的数据墨水比。
2. **骨架恒定**：运行中/完成态/回放共用同一四区骨架，只有区内内容变化——DevTools 十年不变的高级感来源。
3. **选择驱动联动**：点 token → 右栏 Inspector 更新，眼睛只做水平往返——Figma/DevTools 的黄金交互，也把"最后一步的候选"从死数据变成活仪表。
4. **重量预算**：删掉 ✓、箭头、方块边框后，屏幕上唯一的彩色是被测对象本身——仪器安静，标本发光。

## 四、执行顺序（确认后动手）

| 步 | 内容 | 风险 |
|---|---|---|
| S1 | DEBUG 条下沉最底 + 四方块开关改工具行 Tabs（纯布局/形态，逻辑不动） | 低 |
| S2 | 阶段链+PIPELINE 合并为流水线时间轴（数据源已同一，`stages` 事件） | 中 |
| S3 | 右栏 Gauge 统一解剖 + 候选卡改选择联动 Inspector | 中 |
| S4 | composer 槽位固定 + 对比芯片归位 + 说明句收敛 | 低 |
| S5 | 对齐纪律清扫（8pt、右对齐、去 ✓/箭头）+ 全量验证 | 低 |

功能 100% 保留：阶段决策下钻、断点/续跑、对比再跑、专业镜头全在，只是**归位与归一**。
