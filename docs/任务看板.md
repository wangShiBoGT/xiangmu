## 本批次的体验护栏

- 产品定调：观察 AI 的可追溯选择；真实运行本身成为特效。
- **看懂优先于酷炫（出发点铁律）**：用户想看的是「AI 全过程在干什么」。每个可视化画面必须能用一句人话回答「这在告诉你什么」；说不清的画面（只剩炫）算违例，要么配上人话翻译（字幕/此刻卡/出处徽章）要么收起来。评审时对每个画面问一遍「用户看完知道了什么？」。
- 默认体验先让 Explorer 产生问题和好奇；专业字段通过三级下潜提供，不能作为默认数据墙。
- 视觉、动效、3D 都必须对应真实 trace/测量；没有数据时诚实缺席。
- 本文不复述规范：产品原则 See `E5-VolumeI`；认知/视觉 See `AODL/`；交互/Motion See `E5-VolumeIII`；交付流程 See `AOKS/PRODUCT-DELIVERY-WORKFLOW.md`。
