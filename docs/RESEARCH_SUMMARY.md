# 研究阶段总结

## 完成的工作

### ✅ 真实案例收集和分析
- **GPT-4 BS Dataset**：104 个诱发幻觉的 prompt，18 个类别
- **典型案例详解**：编造论文、为错误辩护、甘地名言、趋势外推、Monopoly Man、Alabama 边界
- **核心发现**：
  - 低熵不等于正确（编造的引用熵值 < 1.0）
  - 多次运行一致也可能一致地错（常见误解类）
  - 人发现幻觉的 5 种方式：查资料、逻辑检查、常识判断、多次验证、专业知识

### ✅ 方向研究
- 明确工具的能力边界：不能判断真假，只能标记不确定性
- 产品重新定位：从"幻觉检测器"改为"可用性审计工具"
- 目标用户：科研人员用 AI 整理文献

### ✅ 孤立原型
- `usabilityAudit.ts`：重构版审计模块，移除"置信度评分"
- `AuditReport.tsx`：新版审计报告组件
- 保留所有检测维度：熵值、时间序列、事实性风险、自洽性

### ✅ 产品集成（2026-08-06 新增）
- **P0-1 已修复**：`AuditReport` 已集成到 `ObservePage.tsx`
- 用户可以在完成态点击"查看可用性审计报告"切换视图
- 审计报告接收当前 trace 和所有分支 traces
- 提供"定位到第 X 个 token"功能跳转回原文

### ✅ 界面改进（2026-08-06 新增）
- **P0-4 已修复**：移除"不确定性等级"汇总
- 改为独立展示各维度观察结果（平均熵值、自洽性、风险点总数）
- 移除颜色编码的综合判断（绿色勾号、警告符号）
- 前置重要说明：低熵 ≠ 正确，高熵 ≠ 错误
- 不做综合评分，只提供多维度标记
