# 项目引导

欢迎回来！以下是你可以快速开始的操作：

## 🎯 今天可以做什么

1. **继续开发新功能**
   - 添加用户引导组件
   - 优化现有界面
   
2. **代码质量提升**
   - 运行测试：`npm run test`
   - 代码审查未完成的部分

3. **文档和维护**
   - 更新 README
   - 检查依赖更新

## 🔧 常用命令

```bash
npm run dev          # 启动开发服务器
npm run build        # 构建生产版本
npm run test         # 运行测试套件
npm run lint         # 代码检查
```

## 📂 关键文件

- `src/App.tsx` - 主应用组件
- `src/components/` - UI 组件目录
- `src/lib/` - 工具函数和逻辑
